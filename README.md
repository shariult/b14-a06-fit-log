# Fit Log

Plan your workout for today and the future for a better, healthier and happier life.

## Technologies Used

- Next.js
- Tailwind CSS
- TypeScript
- React.js
- React Toastify

## Project Feature

- Responsive website that works on all phone, tablet and desktop screen sizes.
- Fetching Workouts from an API with proper loading and error handling.
- Sorting workouts based on Duration, Calories burn and Rating in "My plan" page.
- Adding and removing workouts from Today&apos;s plan and Saved.
- React Toastify notification on add, remove workouts.
